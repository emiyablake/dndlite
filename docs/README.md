# Documentação de Design — dndlite

Índice dos Game Design Documents (GDDs) do projeto. Cada documento registra as decisões de design de uma parte do jogo, tomadas antes da implementação.

## Índice

| Documento | Conteúdo |
|---|---|
| [Combate D&D-like](combate-dnd.md) | Mecânica de combate: rolagem 1d20 vs CA, críticos, dados de arma, ataques dos inimigos e balanceamento |
| [Personagens, Atributos e Classes](personagens-classes.md) | Os 3 atributos (Força, Inteligência, Destreza), as classes Fighter e Ranger, criação de personagem e progressão por nível |
| [História e Narrativa](historia.md) | Narrativa por fragmentos estilo Dark Souls, o Lich Vex'thul, cenas interativas de exploração e a estrutura da jornada |

## Convenções

- Todo GDD marca seu status (**implementado** ou não) no cabeçalho
- Decisões em aberto ficam explicitamente listadas em cada documento
- Mudanças de mecânica devem atualizar o GDD correspondente antes do código
